TetherFuseNet

This page is served by your phone (@@HOST@@, version @@VERSION@@), so it works without any proxy settings.

SOCKS is turned off in TetherFuseNet. Option 1 needs it. On the phone, stop the Hotspot, turn on the SOCKS4A/SOCKS5H Proxy switch under Proxy Mode in the Hotspot tab, start the Hotspot again, then reload this page.

Option 1: the whole computer, no proxy settings

Every application, DNS and UDP (QUIC, voice, games) go through your phone, and through the VPN on your phone if it has one. You need sing-box 1.14 or newer, installed once. The script below is short, read it before you run it. Press Ctrl+C to disconnect. 

# Arch / CachyOS. Other distributions: https://sing-box.sagernet.org/installation/package-manager/
sudo pacman -S sing-box
curl -fsS http://@@HOST@@:@@PORT@@/connect.sh -o tfn-connect.sh
less tfn-connect.sh
sudo sh tfn-connect.sh
brew install sing-box
curl -fsS http://@@HOST@@:@@PORT@@/connect.sh -o tfn-connect.sh
less tfn-connect.sh
sudo sh tfn-connect.sh

In an Administrator PowerShell:

winget install SagerNet.sing-box
# open a NEW administrator PowerShell so sing-box is on the PATH, then:
Invoke-WebRequest -UseBasicParsing http://@@HOST@@:@@PORT@@/connect.ps1 -OutFile tfn-connect.ps1
notepad tfn-connect.ps1
powershell -ExecutionPolicy Bypass -File .\tfn-connect.ps1

ping does not work through the phone (it is neither TCP nor UDP). Web pages, SSH, git, downloads, video calls and games do. If UDP misbehaves (a call, a game, QUIC), add --tcp-only to the script (-TcpOnly on Windows): UDP is turned away, applications fall back to TCP, and DNS keeps working.
